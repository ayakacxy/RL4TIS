

# RL4TIS

This repository provides the official implementation for the paper: **"Reinforcement Learning-Based Focality Optimization for Multi-Electrode Temporal Interference Stimulation"**.

**Authors:** Xiayu Chen, Wennan Chan, Sheng Hu, Yingqiang Meng, Runze Liu, Muhammad Mohsin Pathan, Yang Ji, Xiaoxiao Wang, Bensheng Qiu, Yanming Wang

-----

## 🎉 News

We are thrilled to announce that our paper has been accepted for publication in *IEEE Transactions on Biomedical Engineering (TBME)*\!

-----

## Code Status

The source code is currently undergoing a final round of refactoring and documentation to ensure its quality and reproducibility. We will make the complete code publicly available in this repository as soon as possible.

If you require urgent access to the code for your research, please contact the corresponding author at: **ming1258@ustc.edu.cn**.
